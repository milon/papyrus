Mermaid

```mermaid
flowchart TD
  A[Markdown] --> B[Build]
```

Enable in papyrus.php:

'mermaid' => [
    'enabled' => true,
    'format' => 'svg',
    'theme' => 'auto',
    'max_width_mm' => 130,
],

Requires mmdc on PATH. Diagrams cache under .papyrus/cache/mermaid.
