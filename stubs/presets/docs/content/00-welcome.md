# Welcome

Documentation for **{{title}}**.

Edit the chapters under `content/`, then:

```bash
papyrus build:site
papyrus serve
```

Open the printed URL (search needs a real HTTP origin). Deploy the
`export/<slug>-site/` folder to GitHub Pages, Netlify, or any static host.

If this site lives at `https://user.github.io/repo/`, set `site.base_path`
in your Papyrus config to `/repo` (already suggested for many packages).
